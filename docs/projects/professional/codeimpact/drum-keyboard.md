# Drum Keyboard VR

**Role:** Unity Developer

## Overview
A VR text-input system that lets users type by hitting keys with drumsticks.

## Challenge
The client was struggling to get their keyboard package working reliably.

## What I Did
- Fixed several bugs in the existing keyboard package.
- Added **text-to-speech** for typed input.
- Added **customization options** for the keyboard.
- Improved the 3D key models and the overall layout.
